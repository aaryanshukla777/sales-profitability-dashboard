# Sales & Profitability Dashboard

I built this Power BI dashboard to explore sales and profitability across different product categories and sub-categories.

## What the dashboard covers

- Total profit across the dataset
- Average profit margin
- Profit by category
- Profit margin comparison across categories
- Profit by sub-category

## Tools used

- Power BI
- Data visualisation

## Files

- `Sales_Profit_Dashboard.pbix` — the Power BI dashboard
- `Details.csv` — the dataset used in the project
